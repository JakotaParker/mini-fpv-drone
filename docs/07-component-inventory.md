# 07 - Component Inventory

This document contains the physical dimensions and verification status
for every component used in the drone build.

## Measurement Status Legend

  -----------------------------------------------------------------------
  Status                        Description
  ----------------------------- -----------------------------------------
  Manufacturer Specification    Dimensions provided by the manufacturer.

  AliExpress Listing            Dimensions taken from the product
                                listing.

  Estimated                     Estimated dimensions before physical
                                measurements.

  Physically Verified           Measured with calipers after the
                                component arrives.
  -----------------------------------------------------------------------

# Notes

-   Verify all critical dimensions using digital calipers before
    finalizing Frame V2.
-   Update the CAD models if measured dimensions differ from the
    published specifications.
-   Record any manufacturing tolerances or unexpected dimensional
    differences.
-   Mark each component as **Physically Verified** only after direct
    measurement.
